## 通关装饰与小屋

每关首次通关后自动获得并保存一件小物，选关页的场景和游戏顶部的小屋都会随收集变化。选关页展示下一件奖励，各关卡片显示该关奖励；点击“我的小屋”可查看摆放后的场景、五件收藏和下一件的获得条件。首次通关结算的主按钮为“带回小屋”，另有直接继续关卡的入口；重玩则保留普通结算。

“我的小屋”中左滑看下一间，右滑看上一间，也可点击两侧箭头。可挑战某章第一关时，对应小屋即为已解锁；切换仅在这些小屋之间进行，到首尾时对应箭头变淡且不可点击。只解锁一间时保持原有界面。新家具欢迎动画期间暂时停用切换，结束或跳过后可浏览其他房间，仍可继续原来的下一关。切换清理当前家具回应，保留原选关位置、牌局、道具与存档；短拖动、纵向滑动、取消或多指操作不会误点家具或取牌。章节页原有的未解锁小屋静态预览继续保留。

点击“带回小屋”后，新家具在前 0.8 秒渐显落位、闪过小星星，随后小猫主动回应，整个仪式约 3.2 秒。可随时跳过动画或返回结算；结束后可直接继续下一关，第 5 关衔接花房，第 10 关衔接书房，第 15 关衔接露台。奖励在通关时已经保存，动画本身不修改存档：跳过、关闭、刷新或重玩都保留家具，旧收藏也不补播欢迎。每次首次通关的欢迎仅在当前流程播放一次，直接继续关卡视为略过仪式。

第 20 关首次通关的最后一张牌动画结束后，自动显示“谢谢你，把小屋变成了家”，展示 20 关完成和 20 份心意。点击“带回最后一份心意”进入露台，纪念牌落位，小猫欢迎；也可以回到选关或关闭感谢页返回结算。奖励在感谢界面出现前已保存，退出或刷新都保留。重玩不自动弹出感谢页，完成全部关卡后可从选关页或第 20 关结算的“看看小猫的感谢信”再次查看。

## 浏览器试玩

需要本机 Node.js，无第三方依赖。

```powershell
npm start
```

打开 http://127.0.0.1:4173，从选关页进入第一关。点击没有被遮挡的图块，同类图块会在槽位自动归组；三张消除。清空棋盘获胜，槽位满且未形成消除则失败。每局提供 3 次撤回、1 次提示，按钮显示剩余次数，用完后禁用。

末尾锁格显示灰色锁标记，无法存放图块；可用容量填满且没有凑三时失败。最后一个可用位置若凑成三张，则先消除再检查容量。点击锁格只提示“这个空位暂未开放”，当前没有广告请求或解锁奖励。

为后续激励广告预留了 `Game.unlockSlot()`：每次增加一个可用位置，最多恢复到 7 格，按局保存解锁数；撤回不会撤销已获得的槽位，重来会恢复该关初始锁格。将来应仅在广告完整观看成功后调用此接口并保存游戏状态。当前页面没有调用该奖励接口的入口。

首次操作后播放约 20.87 秒的原创电钢琴旋律、分解和弦与低音，循环播放时衔接音符尾音。右上角声音开关同时控制音乐和音效，并保存开关状态。切到后台会暂停音乐和音效，返回前台会恢复已开启的音乐；切换关卡或普通画面更新不会重新从头播。音频随游戏包提供，无需外部音乐服务。

撤回成功才扣次，提示找到可用图块才扣次；找不到路线不扣提示次数。失败时若仍有撤回次数，可以撤回一步继续。重来、进入下一关或通关后重玩获得新一局额度；切换关卡、退出或重新打开会保留原局剩余次数。原版存档没有道具记录时，保留已有局面，并给该局初始的 3 次撤回、1 次提示。

通过当前关后自动解锁下一关，结算页可以进入下一关、重玩或选关。棋盘左上角的返回按钮可回到选关页；各关正在玩的局面分别保留。完成二十关后可自由重玩，切换章节回到四间小屋，或再次查看感谢信。

每次取牌、成功撤回、有效提示、重试和声音切换会自动保存到当前浏览器的本地存储。重新打开页面后点击“继续”可恢复棋盘、暂存槽、撤回历史和剩余道具次数。通关记录和声音设置也会保留。微信版使用设备本地存储，浏览器与微信之间不同步；清除对应应用数据会清除记录。存储被禁用或空间不足时，会提示无法保存，本次游戏仍可继续。

关卡更新会保留既有通关记录、装饰收藏、解锁状态和声音设置。只有布局版本发生变化的关卡才重开进行中局面，避免旧取牌记录套用到新布局；当前版本将旧 42 张第一关重开为 30 张，第 2～5 关的当前版本存档继续恢复。新存档会记录关卡版本，以便后续正确恢复。

浏览器支持鼠标、触屏和 Tab / Enter 键盘操作，Ctrl+Z 可撤回。

## Git 版本管理

项目使用 `main` 作为开发主分支；可体验的里程碑版本使用对应的 `v0.x.x` 标签，当前基线为 `v0.8.0`。后续每次修改完成验证后提交，版本行为和验证结果记录在 `CHANGELOG.md`。微信开发者工具打开同一工程目录后，可在版本管理的 Git 面板查看本地提交；远程推送使用本项目绑定的仓库地址。

远程仓库为 [猫猫消消屋](https://github.com/jh431968914/-)，本地 `origin` 使用 `https://github.com/jh431968914/-.git`，沿用已有的全局 Git 提交署名。`main` 保存后续开发提交，`v0.8.0` 标签标记等距小屋版本基线；分支与版本标签分别同步到 GitHub，微信开发者工具的 Git 面板使用同一本地仓库和远程配置。

源码、原创音频、测试代码、验证脚本、微信项目配置和依赖锁文件纳入版本管理。依赖目录、本机微信配置、截图、日志与微信预览/上传记录由 `.gitignore` 排除。Git 元数据及版本管理辅助文件已从微信小游戏包中排除。

## 文件

- `utils/game.js`：关卡生成、规则、可解性证书和提示求解器。
- `CHANGELOG.md`：各本地版本的行为和验证记录。
- `utils/art.js`：原创矢量猫咪、十八种用品图案、二十件装饰与四间等距房间绘图，无图片依赖。
- `utils/progress.js`：逐关解锁、本地保存、存档验证、局面恢复与通关装饰收藏。
- `utils/audio.js`：共用背景音乐与音效管理，处理首次操作、静音和前后台切换。
- `scripts/difficulty-check.js`：使用简单策略和三步前瞻策略对比二十关的规划要求。
- `scripts/wechat-check.js`：保留的小程序页面适配验证，备份并恢复游戏存档；不适用于当前小游戏入口。
- `utils/view.js`：共用画面、动画、结算、装饰自动摆放与 2.5D 小屋收藏交互。
- `game.js`、`game.json`、`utils/minigame.js`：当前微信小游戏入口和设备适配。
- `pages/game/`：保留的微信小程序页面适配。
- `web/`：本地浏览器试玩。
- `assets/audio/`：三个轻量音效与原创背景音乐；运行 `node scripts/generate-audio.js` 生成音效，运行 `node scripts/generate-music.js` 生成背景音乐。

目前为四章二十关玩法原型：无排行榜、登录和广告。浏览器已验证的结果与微信真机验证应分别记录；导入工程不代表已完成真机测试。
